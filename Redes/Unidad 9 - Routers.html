9.1 Routers - Fundamentos

Un router interconecta redes distintas y decide la mejor ruta para enviar paquetes IP. Funciona en la capa 3 del modelo OSI.

Funciones principales

  • Encaminamiento (Routing)
  • Segmentación de redes
  • NAT/PAT
  • ACLs y seguridad
  • Servicios DHCP y VPN
📡 El router toma decisiones usando tablas de enrutamiento.
⚠ Sin router no puede existir comunicación entre redes distintas.

9.2 Routers - Hardware y componentes

Los routers incluyen CPU, RAM, Flash, ROM e interfaces físicas.

Componente Función
RAM Running-config y tablas
NVRAM Startup-config
Flash Imagen IOS
ROM Bootstrap y ROMMON

Interfaces comunes

  • FastEthernet
  • GigabitEthernet
  • Serial
  • Consola
  • Auxiliar
🖥 Los routers pueden ser fijos o modulares.
❌ Si falla la Flash, el IOS puede no cargar.

¿Dónde se almacena el IOS?



9.3 Cisco IOS

Cisco IOS es el sistema operativo usado por routers y switches Cisco.

Características

  • CLI (Command Line Interface)
  • Routing y Switching
  • Seguridad y ACLs
  • SSH y administración remota
  • QoS y VPN

Archivos importantes

  • running-config
  • startup-config
  • IOS image
⚙ IOS es altamente modular.
⚠ Running-config está en RAM y se pierde si no se guarda.

¿Dónde se guarda la configuración activa?



9.4 Cisco IOS - Proceso de arranque

El arranque del router sigue varias etapas.

  1. POST
  2. Carga Bootstrap
  3. Carga IOS
  4. Carga startup-config

POST

  • Verifica CPU
  • Verifica RAM
  • Verifica hardware
🚀 El Bootstrap carga el IOS desde Flash.
❌ Si falla el IOS → entra en ROMMON mode.

9.5 Configuración básica de routers

Los routers domésticos suelen configurarse mediante interfaz web. Los routers Cisco empresariales usan consola, Telnet o SSH.

Pasos recomendados

  • Hostname
  • Enable secret
  • Usuarios
  • SSH
  • Configurar interfaces
  • Guardar configuración
🔐 SSH es más seguro que Telnet.
⚠ Telnet transmite datos en texto plano.

¿Qué protocolo es seguro?



9.6 Comandos para la configuración del router

Clave de administrador

enable
configure terminal
enable secret admin1234

Configurar IP

interface GigabitEthernet0/0
ip address 192.168.1.1 255.255.255.0
no shutdown

Configurar DHCP

ip dhcp pool LAN
network 192.168.1.0 255.255.255.0
default-router 192.168.1.1
dns-server 8.8.8.8
🛠 El comando no shutdown activa la interfaz.
❌ Error típico: olvidar guardar la configuración.

9.7 Router Home

Los routers domésticos integran: router + switch + Wi-Fi.

Características comunes

  • IP LAN: 192.168.1.1
  • Servidor DHCP
  • NAT/PAT
  • Wi-Fi integrado
  • Switch interno
🏠 Un router doméstico incluye múltiples dispositivos en uno.
⚠ Cambiar la contraseña por defecto es obligatorio.
