REPASO GENERAL DE REDES

CONCEPTOS BÁSICOS DE REDES

IPV4

Protocolo de direccionamiento que identifica dispositivos en una red mediante direcciones de 32 bits divididas en 4 octetos → 192.168.1.10

Subnetting

Técnica para dividir una red grande en subredes más pequeñas para mejorar organización y rendimiento.

→ Ejemplo:

Imagina que tienes una red grande llamada 192.168.1.0/24. Esa red puede tener hasta 254 dispositivos conectados (hosts). El subnetting consiste en “partir” esa red en redes más pequeñas para organizar mejor los equipos, mejorar seguridad y evitar demasiado tráfico.

La máscara /24 significa:

255.255.255.0255.255.255.0255.255.255.0

Eso deja 8 bits para hosts, así que:

28−2=2542^8 - 2 = 25428−2=254

(Se restan 2 porque una IP es la dirección de red y otra es broadcast).

Si dividimos la red en 2 subredes, “tomamos” 1 bit de hosts y pasamos a /25:

255.255.255.128255.255.255.128255.255.255.128

Ahora quedan 7 bits para hosts:

27−2=1262^7 - 2 = 12627−2=126

Por tanto obtenemos:

  • Subred 1: 192.168.1.0/25
    • Red: 192.168.1.0
    • Hosts válidos: 192.168.1.1 – 192.168.1.126
    • Broadcast: 192.168.1.127
  • Subred 2: 192.168.1.128/25
    • Red: 192.168.1.128
    • Hosts válidos: 192.168.1.129 – 192.168.1.254
    • Broadcast: 192.168.1.255

Así, en vez de una sola red con 254 equipos, tienes dos redes separadas con 126 equipos cada una.

Clases

Forma antigua de clasificar redes IPv4 según el rango de direcciones y tamaño:

  • A (1.0.0.0–126.0.0.0)
  • B (128.0.0.0–191.255.0.0)
  • C (192.0.0.0–223.255.255.0)

Máscaras

Indican qué parte de una IP corresponde a la red y cuál a los hosts.

→ Ejemplo: 255.255.255.0 o /24.

Subredes/ Hosts

Una subred es una parte más pequeña creada a partir de una red principal para organizar mejor los dispositivos. Los hosts son los equipos conectados dentro de esa subred, como ordenadores, móviles o impresoras.


Por ejemplo, la red 192.168.1.0/24 tiene 256 direcciones totales, pero solo 254 pueden usarse para hosts porque una IP identifica la red (192.168.1.0) y otra se reserva para broadcast (192.168.1.255). Los hosts utilizables serían desde 192.168.1.1 hasta 192.168.1.254.

IPs Excepciones:

Direcciones reservadas con funciones especiales, como 127.0.0.1 (loopback), 0.0.0.0 (red por defecto) o 255.255.255.255 (broadcast).

IPv6 Abreviación

Las direcciones IPv6 son muy largas porque usan 128 bits y se escriben en 8 bloques hexadecimales separados por :. Para hacerlas más fáciles de leer, existen dos reglas de abreviación:

  1. Eliminar ceros a la izquierda en cada bloque.
  1. Reemplazar bloques consecutivos de 0000 por ::, pero solo una vez por dirección.
  • fe80:0000:0000:0000:02aa:00ff:fe28:9c5a → fe80::2aa:ff:fe28:9c5a
  • 2001:0db8:0000:0000:0000:ff00:0042:8329 → 2001:db8::ff00:42:8329

Modelo OSI y PDU

El Modelo OSI organiza la comunicación de red en 7 capas, donde cada una tiene una función específica. Cada capa maneja una PDU (Protocol Data Unit) distinta y utiliza ciertos protocolos.

Capa Función PDU Protocolos / Ejemplos
7. Aplicación Interfaz entre el usuario y la red; ofrece servicios de red a las aplicaciones. Datos HTTP, HTTPS, FTP, SMTP, DNS
6. Presentación Traduce formatos de datos, cifrado y compresión. Datos SSL/TLS, JPEG, ASCII, MPEG
5. Sesión Establece, mantiene y cierra sesiones de comunicación. Datos NetBIOS, RPC, PPTP
4. Transporte Controla el envío de datos extremo a extremo y la fiabilidad. Segmento (TCP) / Datagrama (UDP) TCP, UDP
3. Red Se encarga del direccionamiento lógico y el enrutamiento. Paquete IPv4, IPv6, ICMP, OSPF
2. Enlace de Datos Controla el acceso al medio y la comunicación entre dispositivos de la misma red. Trama Ethernet, Wi-Fi (802.11), PPP, MAC
1. Física Transmite bits por medios físicos como cables o señales. Bits RJ45, fibra óptica, USB, Bluetooth

Modelo TCP/IP

El Modelo TCP/IP es el modelo usado en Internet y organiza la comunicación en 4 capas. Cada capa cumple una función específica y utiliza distintos protocolos.

Capa Función PDU Protocolos / Ejemplos
4. Aplicación Proporciona servicios de red a las aplicaciones del usuario. Datos HTTP, HTTPS, FTP, DNS, SMTP, DHCP
3. Transporte Gestiona la comunicación entre dispositivos y la fiabilidad de los datos. Segmento (TCP) / Datagrama (UDP) TCP, UDP
2. Internet Se encarga del direccionamiento lógico y el enrutamiento entre redes. Paquete IPv4, IPv6, ICMP, ARP
1. Acceso a la Red Controla la transmisión física de datos en la red local. Trama / Bits Ethernet, Wi-Fi, PPP, MAC

Relación con OSI

El modelo TCP/IP simplifica el OSI:

  • Aplicación TCP/IP = Capas 7, 6 y 5 de OSI
  • Transporte TCP/IP = Capa 4 de OSI
  • Internet TCP/IP = Capa 3 de OSI
  • Acceso a la Red TCP/IP = Capas 2 y 1 de OSI

Detección y comprobación de errores en redes

Cuando los datos viajan por una red pueden producirse errores por ruido, interferencias o fallos físicos. Para comprobar que la información llegue correctamente, distintas capas del modelo OSI realizan verificaciones.

En Ethernet, la información viaja dentro de una trama formada por cabecera, datos y un trailer:

| Cabecera | Datos | Trailer |

El trailer contiene el FCS (Frame Check Sequence), un valor que sirve para detectar errores en la transmisión. Ese valor se calcula usando:

CRC

El emisor calcula el CRC antes de enviar la trama y el receptor lo vuelve a calcular al recibirla. Si ambos resultados coinciden, la trama es válida; si no coinciden, significa que algún bit cambió durante el envío.

En la Capa 2 (Enlace de Datos) se usan CRC y FCS para detectar errores de bits en toda la trama Ethernet.

| Header Ethernet | Datos | FCS |

En la Capa 3 (Red), IP utiliza un checksum que solo verifica la cabecera IP, comprobando que datos como la IP origen, destino o TTL no se hayan corrompido.

| Cabecera IP |

En la Capa 4 (Transporte), TCP y UDP usan checksum para comprobar tanto la cabecera como los datos.

| Header TCP/UDP | Datos |

TCP además puede reenviar paquetes perdidos y garantizar que lleguen en el orden correcto, mientras que UDP solo verifica errores pero prioriza la velocidad.

Redes

  • WAN (Wide Area Network): Red de área amplia que conecta dispositivos o redes a grandes distancias, incluso entre países.Ejemplo: Internet.
  • CAN (Campus Area Network): Red que conecta varios edificios dentro de un campus o institución.Ejemplo: la red de una universidad.
  • PAN (Personal Area Network): Red de corto alcance para dispositivos personales.Ejemplo: conexión Bluetooth entre móvil y auriculares.
  • LAN (Local Area Network): Red local que conecta dispositivos en un área pequeña como una casa, oficina o aula.Ejemplo: red Wi-Fi de casa.
  • MAN (Metropolitan Area Network): Red que cubre una ciudad o zona metropolitana.Ejemplo: red que conecta varias sedes de una empresa en una misma ciudad.
  • VLAN (Virtual Local Area Network): División lógica de una LAN para separar dispositivos aunque estén conectados al mismo switch físico.Ejemplo: separar la red de alumnos y profesores.
  • WLAN (Wireless Local Area Network): LAN inalámbrica que usa Wi-Fi para conectar dispositivos sin cables.Ejemplo: red Wi-Fi de una cafetería.

Perturbaciones (Interferencias)

Las perturbaciones son alteraciones que afectan a la señal durante la transmisión de datos y pueden provocar errores en la comunicación.

  • Ruido: Señales externas no deseadas que interfieren con la transmisión.Ejemplo: interferencias eléctricas en un cable de red.
  • Atenuación: Pérdida de intensidad de la señal a medida que recorre una distancia.Ejemplo: una señal Wi-Fi débil lejos del router.
  • Distorsión: Alteración de la forma original de la señal durante la transmisión.Ejemplo: datos que llegan modificados por interferencias o retrasos.

Modos de transmisión

Los modos de transmisión indican cómo se envían y reciben los datos entre dispositivos.

  • Simplex: La comunicación va en un solo sentido.Ejemplo: una televisión recibe señal pero no envía información.
  • Half-duplex: La comunicación va en ambos sentidos, pero no al mismo tiempo.Ejemplo: un walkie-talkie.
  • Full-duplex: La comunicación ocurre en ambos sentidos simultáneamente.Ejemplo: una llamada telefónica o una red Ethernet moderna.

Cables Ethernet

Cables Ethernet RJ45

Los cables Ethernet con conector RJ45 se usan en redes LAN para conectar dispositivos como ordenadores, switches y routers. Funcionan bajo el estándar:

Ethernet (IEEE 802.3)

Existen distintos tipos de cable según el nivel de protección frente a interferencias:

  • UTP (Unshielded Twisted Pair): cable sin blindaje. Es el más común y económico.Ejemplo: redes domésticas y oficinas.
  • STP (Shielded Twisted Pair): cable con blindaje metálico para reducir interferencias.Ejemplo: entornos industriales.
  • FTP (Foiled Twisted Pair): cable con una lámina metálica que protege todos los pares internos.Ejemplo: oficinas con muchos dispositivos electrónicos.
  • SFTP (Shielded Foiled Twisted Pair): combina malla y lámina de protección para máxima reducción de ruido.Ejemplo: centros de datos.

Cables de fibra óptica

Los cables de fibra óptica transmiten datos mediante pulsos de luz en lugar de electricidad. Están formados por hilos de vidrio o fibra, recubrimientos plásticos y materiales de refuerzo como kevlar, lo que les permite alcanzar grandes velocidades y largas distancias con muy poca interferencia.

Sus principales ventajas son:

  • Mayor velocidad de transmisión.
  • Menor pérdida de señal.
  • Inmunidad a interferencias electromagnéticas.
  • Mayor seguridad y estabilidad.

Tipos de fibra óptica

  • Monomodo (Single Mode): utiliza un solo camino de luz, lo que permite transmitir datos a largas distancias y altas velocidades. Tiene un núcleo muy fino y suele ser más cara.Ejemplo: conexiones entre ciudades o redes de proveedores de Internet.
  • Multimodo (Multi Mode): utiliza varios caminos de luz al mismo tiempo. Es más económica, pero funciona mejor en distancias cortas porque la señal se dispersa más fácilmente.Ejemplo: redes internas de edificios o centros de datos.

Tipos de fibra monomodo

La fibra monomodo utiliza un único haz de luz, lo que permite transmitir datos a grandes distancias con muy poca pérdida de señal.

  • OS1: fibra monomodo diseñada para interiores, normalmente usada en edificios y redes internas.Ejemplo: cableado de fibra dentro de oficinas o centros de datos.
  • OS2: fibra monomodo para exteriores y largas distancias. Tiene menor atenuación y mayor rendimiento.Ejemplo: conexiones entre ciudades o redes de operadores.

Tipos de fibra multimodo

La fibra multimodo permite varios caminos de luz simultáneos. Es más económica y se usa principalmente en distancias cortas.

Tipo Distancia / Velocidad Características
OM1 300 m – 1 Gbps Fibra multimodo básica y antigua
OM2 600 m – 1 Gbps Mayor alcance que OM1
OM3 300 m – 10 Gbps Optimizada para altas velocidades
OM4 550 m – 10/40 Gbps Mejor rendimiento y alcance
OM5 550 m – 40/100 Gbps Más eficiente y preparada para mayores velocidades

Conectores de fibra óptica

Los conectores unen los cables de fibra a dispositivos de red.

  • ST (Straight Tip): conector redondo y antiguo que funciona girándolo para fijarlo.Ejemplo: instalaciones antiguas de fibra.
  • SC (Subscriber Connector): conector cuadrado de presión, muy utilizado en telecomunicaciones.Ejemplo: routers de fibra FTTH.
  • LC (Lucent Connector): conector pequeño tipo clip, muy usado actualmente por su tamaño reducido.Ejemplo: switches y centros de datos.

Dispositivos para comunicaciones

  • Router: Dispositivo que conecta diferentes redes y dirige los paquetes de datos hacia su destino usando direcciones IP. Trabaja principalmente en la Capa 3 (Red).

    Ejemplo: el router de casa que conecta la red local a Internet.

  • Hub: Dispositivo antiguo que enviaba la información a todos los equipos conectados sin distinguir destinatarios. Trabaja en la Capa 1 (Física) y actualmente está obsoleto por ser poco eficiente.

    Ejemplo: antiguas redes Ethernet compartidas.

  • Switch: Dispositivo que conecta equipos dentro de una LAN y envía los datos solo al dispositivo correcto usando direcciones MAC. Trabaja en la Capa 2 (Enlace de Datos).

    Ejemplo: conexión de varios PCs en una oficina.

  • Switch Capa 3: Switch avanzado que además de funciones de switching puede realizar enrutamiento entre redes o VLANs utilizando IP. Combina funciones de Capa 2 y Capa 3.

    Ejemplo: comunicación entre distintas VLANs en una empresa.

  • AP (Access Point): Punto de acceso que permite conectar dispositivos inalámbricos a una red cableada mediante Wi-Fi.

    Ejemplo: un punto Wi-Fi en una oficina o universidad.

Topologías de red

Las topologías de red describen la forma en que los dispositivos están conectados dentro de una red.

  1. Estrella: Todos los dispositivos se conectan a un punto central, normalmente un switch o router. Es la topología más utilizada porque si un equipo falla, el resto sigue funcionando.

    Ejemplo: redes Ethernet actuales en oficinas y casas.

  1. Árbol: Estructura jerárquica formada por varias redes en estrella conectadas entre sí. Facilita la expansión de grandes redes.

    Ejemplo: red de una universidad con varios edificios y departamentos.

  1. Malla: Cada dispositivo puede conectarse con varios o todos los demás, ofreciendo gran redundancia y tolerancia a fallos.

    Ejemplo: redes de proveedores de Internet.

  1. Bus: Todos los dispositivos comparten un único cable principal. Fue común en redes antiguas pero actualmente casi no se utiliza.

    Ejemplo: antiguas redes Ethernet coaxiales.

  1. Anillo: Los dispositivos se conectan formando un círculo y los datos viajan de un equipo a otro hasta llegar al destino.

    Ejemplo: redes Token Ring.

Estándares IEEE 802.X

IEEE 802.11 — Wi-Fi

Estándar para redes inalámbricas WLAN. Define cómo se comunican los dispositivos mediante Wi-Fi.

Ejemplo: conexión inalámbrica de móviles y portátiles a un router.

IEEE 802.3 — Ethernet

Estándar para redes Ethernet cableadas. Define transmisión de datos, cableado y velocidades en redes LAN.

Ejemplo: conexión por cable RJ45 entre un PC y un switch.

IEEE 802.15.1 — Bluetooth

Estándar para redes PAN de corto alcance mediante Bluetooth.

Ejemplo: conexión entre auriculares inalámbricos y un móvil.

IEEE 802.16 — WiMAX

Estándar de comunicación inalámbrica de largo alcance usado para acceso a Internet metropolitano.

Ejemplo: cobertura inalámbrica en zonas rurales o grandes ciudades.

IEEE 802.1Q — Dot1Q / Trunk

Estándar usado en enlaces Trunk para etiquetar VLANs dentro de una misma conexión física mediante encapsulación Dot1Q.

Ejemplo: comunicación de varias VLANs entre switches.

Wi-Fi

Wi-Fi es una tecnología inalámbrica basada en el estándar:

IEEE 802.11

Permite conectar dispositivos a una red sin usar cables mediante ondas de radio.

Las bandas más utilizadas son:

  • 2.4 GHz
  • 5 GHz

La banda 2.4 GHz ofrece mayor alcance y puede atravesar mejor paredes y obstáculos, aunque tiene menor velocidad y suele sufrir más interferencias porque muchos dispositivos la utilizan.

→ Ejemplo: redes domésticas con dispositivos alejados del router.

La banda 5 GHz ofrece mayor velocidad y menor interferencia, pero tiene menos alcance y atraviesa peor los obstáculos.

→ Ejemplo: streaming, videojuegos online o conexiones de alta velocidad cerca del router.

Seguridad

La seguridad de una red Wi-Fi no depende de la frecuencia utilizada (2.4 GHz o 5 GHz), sino del tipo de cifrado y autenticación configurados en la red.

Los principales protocolos de seguridad Wi-Fi son:

  • WEP (Wired Equivalent Privacy): sistema antiguo y poco seguro. Sus claves pueden romperse fácilmente, por lo que actualmente está obsoleto.
    → Ejemplo: redes Wi-Fi antiguas.
  • WPA (Wi-Fi Protected Access): mejora de WEP que añadió mayor seguridad mediante cifrado dinámico.
    → Ejemplo: primeras redes Wi-Fi domésticas seguras.
  • WPA2: estándar más utilizado durante muchos años. Usa cifrado AES y ofrece una seguridad mucho mayor.
    → Ejemplo: la mayoría de routers domésticos modernos.
  • WPA3: versión más reciente y segura. Mejora la protección frente a ataques de fuerza bruta y aumenta la privacidad de la conexión.
    → Ejemplo: routers y dispositivos Wi-Fi actuales de última generación.

PROTOCOLOS (OJITO A ESTA)

RIP (Routing Information Protocol)

Protocolo de enrutamiento dinámico que elige la ruta con menor número de saltos. Su límite es 15 saltos; 16 significa red inalcanzable. Funciona enviando periódicamente tablas de rutas a otros routers.

  • Capa: Capa 3 (Red)
  • Transporte: UDP 520
  • Tipo: IGP (Interior Gateway Protocol)

Ejemplo: pequeñas redes internas con pocos routers.

OSPF (Open Shortest Path First)

Protocolo de enrutamiento que calcula la ruta más corta usando el algoritmo de Dijkstra (SPF). Los routers comparten información del estado de la red para encontrar la mejor ruta.

  • Capa: Capa 3
  • Protocolo IP: 89
  • Tipo: IGP

Ejemplo: redes empresariales grandes.

EIGRP (Enhanced Interior Gateway Routing Protocol)

Protocolo de Cisco híbrido que selecciona la mejor ruta según ancho de banda, retardo y otros factores. Usa el algoritmo DUAL para converger rápidamente.

  • Capa: Capa 3
  • Protocolo IP: 88
  • Compatible con: IPv4 e IPv6

Ejemplo: redes Cisco corporativas.

BGP (Border Gateway Protocol)

Protocolo usado para intercambiar rutas entre Sistemas Autónomos (AS) en Internet. Funciona mediante relaciones de “peering” entre routers.

  • Capa: Capa 4 / Aplicación
  • Transporte: TCP 179
  • Tipo: EGP (Exterior Gateway Protocol)

Ejemplo: comunicación entre proveedores de Internet.

DNS (Domain Name System)

Traduce nombres de dominio en direcciones IP.

google.com → 142.250.x.x

Usa distintos registros como:

  • A → IPv4
  • AAAA → IPv6
  • MX → correo
  • CNAME → alias
  • Capa: Aplicación
  • Puertos: UDP/TCP 53

Ejemplo: acceder a una página web usando un nombre en vez de una IP.

HTTP / HTTPS

Protocolos usados para navegar por páginas web. HTTP transmite información y HTTPS añade cifrado SSL/TLS para seguridad.

  • Capa: Aplicación
  • Puertos:
    • HTTP → 80
    • HTTPS → 443

Ejemplo: navegación web.

IP (IPv4 / IPv6)

Protocolo encargado del direccionamiento lógico y envío de paquetes entre redes.

  • Capa: Capa 3 (Red)

Ejemplo: asignar IPs a dispositivos.

ICMP (Internet Control Message Protocol)

Protocolo usado para diagnóstico y control de errores. No transporta datos de usuario.

ping → Echo Request / Echo Reply
  • Capa: Capa 3
  • No orientado a conexión.

Ejemplo: comando ping.

DHCP (Dynamic Host Configuration Protocol)

Asigna automáticamente direcciones IP y otros parámetros de red.

Proceso:

DORA:
Discover → Offer → Request → Acknowledge
  • Capa: Aplicación
  • Puertos:
    • UDP 67
    • UDP 68

Ejemplo: un móvil conectándose al Wi-Fi y obteniendo IP automática.

Telnet / SSH

Protocolos para administración remota de dispositivos.

  • Telnet transmite datos sin cifrar.
  • SSH cifra toda la comunicación.
  • Capa: Aplicación
  • Puertos:
    • Telnet → 23
    • SSH → 22

Ejemplo: configurar un router remotamente.

SMTP / IMAP / POP3

Protocolos de correo electrónico.

  • SMTP → envío de correos.
  • IMAP → sincronización del correo con el servidor.
  • POP3 → descarga correos al dispositivo.
  • Capa: Aplicación

Ejemplo: Gmail o Outlook.

TCP (Transmission Control Protocol)

Protocolo orientado a conexión que garantiza entrega correcta y ordenada de datos.

Establece conexión mediante:

SYN → SYN-ACK → ACK

(Three-Way Handshake)

  • Capa: Capa 4 (Transporte)

Ejemplo: navegación web o transferencia de archivos.

UDP (User Datagram Protocol)

Protocolo no orientado a conexión. Envía datos rápidamente sin confirmar entrega.

  • Menor latencia.
  • Más rápido pero menos fiable.
  • Capa: Capa 4

Ejemplo: streaming, videojuegos o videollamadas.

FTP / SFTP

Protocolos de transferencia de archivos.

  • FTP → sin cifrado.
  • SFTP → transferencia segura mediante SSH.
  • Capa: Aplicación
  • Puertos:
    • FTP → 21
    • SFTP → 22

Ejemplo: subir archivos a un servidor.

ARP / RARP

ARP relaciona direcciones IP con direcciones MAC dentro de una LAN.

IP → MAC

RARP hacía el proceso inverso y actualmente está obsoleto.

  • Capa: Capa 2 y 3

Ejemplo: un PC buscando la MAC del gateway.

STP (Spanning Tree Protocol)

Protocolo que evita bucles entre switches. Elige un switch principal llamado Root Bridge y bloquea enlaces redundantes.

  • Capa: Capa 2
  • IEEE: 802.1D
  • Variante rápida: RSTP (802.1w)

Ejemplo: redes con varios switches conectados.

VTP (VLAN Trunking Protocol)

Protocolo Cisco que distribuye automáticamente información de VLANs entre switches mediante enlaces trunk.

Modos:

  • Server
  • Client
  • Transparent
  • Capa: Capa 2

Ejemplo: creación automática de VLANs en varios switches.

NAT / PAT

Tecnologías que traducen direcciones IP privadas a públicas.

  • NAT → traducción IP ↔ IP
  • PAT → varias IP privadas comparten una IP pública usando puertos. 
IP privada ↔ IP pública
  • Capa: Capa 3

Ejemplo: varios dispositivos de casa usando una sola IP pública.

Tier de proveedores de INternet (ISP)

  • Tier 1: Proveedores globales que forman el núcleo de Internet. No pagan tránsito porque intercambian tráfico entre ellos directamente (peering).Ejemplo: grandes operadores internacionales.
  • Tier 2: Proveedores que combinan peering con compra de tránsito a Tier 1 para llegar a otras redes.Ejemplo: operadores nacionales o grandes empresas de telecomunicaciones.
  • Tier 3: Proveedores locales que compran acceso a Tier 1 o Tier 2 para ofrecer Internet a usuarios finales.Ejemplo: ISP regionales.
  • Tier 4: Redes internas o pequeñas compañías que dependen completamente de otros ISP para conectarse a Internet.Ejemplo: redes de pequeñas empresas o comunidades.

Herramientas

  • Crimpadora: herramienta para colocar conectores RJ45.
  • Pelacables: retira el recubrimiento del cable.
  • Cortacables: corta cables de red o fibra.
  • Tester de red: comprueba conexiones RJ45.
  • Certificador de cableado (Fluke): verifica calidad y rendimiento del cableado.
  • OTDR: analiza y detecta fallos en fibra óptica.
  • Voltímetro / Multímetro: mide voltaje, corriente y resistencia.
  • Tuercas y tornillos enjaulados: fijan equipos en racks.
  • Fusionadora de fibra: une o repara cables de fibra óptica.
  • Puntero láser: ayuda a identificar fibras ópticas.
  • Destornilladores / taladro / guías pasacables: herramientas de instalación física.
  • Canaletas / Patch Panels / regletas / ventiladores: organización y gestión del cableado y energía.
  • Racks: armarios para montar equipos de red.
  • Ropa de seguridad: protección personal como casco, botas, guantes o gafas.
