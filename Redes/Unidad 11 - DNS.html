11.1 DNS

DNS (Domain Name System) traduce nombres de dominio a direcciones IP.

Ejemplo

🌐 google.com → 142.250.x.x
  • Más fácil que memorizar IPs
  • Sistema distribuido
  • Jerárquico
  • Fundamental en Internet
⚠ Sin DNS tendríamos que escribir IPs manualmente.

11.2 DNS - Historia

Antes de DNS se usaba un archivo llamado hosts.txt.

Problemas del sistema antiguo

  • No escalable
  • Difícil de actualizar
  • Muchos conflictos
📜 DNS fue creado en 1983.
⚠ El archivo hosts sigue existiendo actualmente.

11.6 DNS - Funcionamiento

DNS funciona mediante consultas recursivas e iterativas.

Proceso básico

  1. Cliente consulta resolver
  2. Resolver pregunta root
  3. Root indica TLD
  4. TLD indica servidor autoritativo
  5. Respuesta final
📡 El resolver DNS suele pertenecer al ISP o a Google/Cloudflare.
⚠ Cada salto añade latencia.

11.7 Resolución de nombres en un servidor DNS

Los servidores DNS responden usando registros.

Herramientas útiles

nslookup google.com

dig google.com

Tipos de resolución

  • Forward Lookup
  • Reverse Lookup
🔍 Reverse lookup usa registros PTR.
❌ Sin registros correctos pueden fallar servicios.

11.8 Cachés y registros DNS

DNS usa caché para acelerar consultas.

Registros comunes

Registro Función
A IPv4
AAAA IPv6
CNAME Alias
MX Correo
PTR Reverse lookup
⚡ La caché DNS reduce tráfico y tiempo de respuesta.
⚠ TTL determina cuánto dura la caché.
