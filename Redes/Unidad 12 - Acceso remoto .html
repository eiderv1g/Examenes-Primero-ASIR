12.1 Acceso remoto en Cisco

Los dispositivos Cisco pueden administrarse de forma remota mediante Telnet o SSH.

Protocolos principales

Protocolo Seguridad Puerto
Telnet No cifrado 23
SSH Cifrado 22
🔐 SSH es el estándar actual para administración remota.
❌ Telnet transmite contraseñas en texto plano.

12.2 ¿Mi equipo soporta SSH?

No todos los dispositivos Cisco soportan SSH. Es necesario verificar versión IOS y capacidades.

Comandos útiles

show version
show ip ssh

Requisitos comunes

  • IOS con soporte criptográfico
  • Hostname configurado
  • Dominio configurado
  • Usuario local
🛠 SSH requiere capacidades criptográficas en IOS.
⚠ Algunos Packet Tracer antiguos no soportan SSH correctamente.

12.3 Generar claves RSA

SSH necesita claves RSA para cifrado.

Pasos básicos

  1. Configurar hostname
  2. Configurar dominio
  3. Generar claves RSA

Ejemplo

hostname Router1

ip domain-name empresa.local

crypto key generate rsa
🔑 Cuanto mayor sea la clave RSA, mayor seguridad.
⚠ Claves de 1024 o 2048 bits son comunes.

12.4 Activar SSH y desactivar Telnet

Buenas prácticas Cisco recomiendan usar solo SSH.

Configuración típica

username admin secret Cisco123

line vty 0 4
transport input ssh
login local

ip ssh version 2

Explicación

  • transport input ssh → bloquea Telnet
  • login local → usa usuarios locales
  • ip ssh version 2 → versión segura
🛡 SSHv2 es más seguro que SSHv1.
❌ Error típico: olvidar crear usuario local.
