Resumen interactivo sobre OSPF, EIGRP y BGP.

14.1 Open Shortest Path First (OSPF)

OSPF es un protocolo IGP de estado de enlace.

  • Link-State
  • Usa algoritmo SPF
  • Muy escalable
  • Convergencia rápida
🛣 OSPF calcula la mejor ruta usando coste.
⚠ OSPF usa áreas para escalar.

¿Qué tipo de protocolo es OSPF?



14.2 OSPF - Paso a paso

Proceso OSPF

  1. Descubrir vecinos
  2. Intercambiar LSAs
  3. Crear LSDB
  4. Calcular SPF
  5. Actualizar tabla routing
📡 Hello Packets descubren vecinos.
❌ Temporizadores diferentes impiden adyacencia.

¿Qué paquetes descubren vecinos?



14.3 OSPF - Configuración y administración

router ospf 1
network 192.168.1.0 0.0.0.255 area 0

Comandos útiles

  • show ip ospf neighbor
  • show ip route
  • show ip ospf interface
⚙ Area 0 = backbone OSPF.

¿Qué área es el backbone?



14.4 OSPF - Diagnóstico de incidencias

Problemas comunes

  • Área incorrecta
  • Timers distintos
  • Autenticación diferente
  • Wildcard errónea
🛠 El estado FULL indica adyacencia correcta.
⚠ EXSTART puede indicar problemas MTU.

¿Qué estado indica vecindad correcta?



14.5 EIGRP

EIGRP es un protocolo avanzado Cisco.

  • Híbrido
  • Muy rápido
  • Bajo consumo CPU
  • Usa DUAL
🚀 EIGRP converge muy rápido.
⚠ Originalmente propietario Cisco.

¿Qué algoritmo usa EIGRP?



14.6 EIGRP - Tipo de paquete

Paquete Función
Hello Vecinos
Update Rutas
Query Buscar rutas
Reply Responder consultas
ACK Confirmación
📨 Hello mantiene adyacencias.

¿Qué paquete confirma recepción?



14.7 EIGRP - El algoritmo DUAL

DUAL garantiza rutas libres de bucles.

Conceptos

  • Successor
  • Feasible Successor
  • Feasible Distance
🛣 Successor = mejor ruta.
⚠ Feasible Successor = backup inmediata.

¿Qué es un Feasible Successor?



14.8 EIGRP - DUAL paso a paso

  1. Aprender rutas
  2. Seleccionar Successor
  3. Buscar Feasible Successor
  4. Actualizar rutas
⚡ DUAL evita recalcular toda la red.
❌ Si no hay FS → Active State.

¿Qué ocurre si no existe FS?

router eigrp 10
network 192.168.1.0
no auto-summary
⚙ El número AS debe coincidir.
⚠ EIGRP usa multicast 224.0.0.10.

¿Qué debe coincidir en EIGRP?



14.10 Protocolos Externos (EGP) - BGP

BGP conecta Sistemas Autónomos.

  • EGP
  • Path Vector
  • Usado en Internet
🌍 BGP mueve tráfico global Internet.

¿Qué tipo de protocolo es BGP?



14.11 BGP - Border Gateway Protocol

Características

  • Muy escalable
  • Basado en políticas
  • TCP puerto 179
📡 BGP usa TCP para fiabilidad.
⚠ BGP converge más lento que OSPF.

¿Qué puerto usa BGP?



14.12 BGP - Paso a paso

  1. Establecer TCP
  2. Intercambiar OPEN
  3. Enviar UPDATE
  4. Mantener KEEPALIVE
🔄 KEEPALIVE mantiene sesión BGP.

¿Qué paquete mantiene BGP?



14.13 BGP - Ciclo de mantenimiento

Estados BGP

  • Idle
  • Connect
  • OpenSent
  • OpenConfirm
  • Established
✅ Established = sesión operativa.
❌ Idle constante = problema configuración.

¿Qué estado indica funcionamiento correcto?



14.14 BGP - Configuración y administración

router bgp 65001

Comandos útiles

  • show ip bgp
  • show ip bgp summary
  • show ip route
⚙ Cada AS tiene un número único.
