Unidad 7 - Protocolos

Resumen interactivo sobre protocolos de red, routing, DHCP y STP. Basado en resúmens personales

7.1 Protocolo IP

IP identifica y transporta paquetes entre redes.

  • No orientado a conexión
  • No garantiza entrega
  • Usa direcciones IP
  • Capa 3 OSI
🌍 IP es la base de Internet.
⚠ IP no corrige errores: eso lo hace TCP.

¿En qué capa OSI trabaja IP?



7.2 TCP

  • Orientado a conexión
  • Fiable
  • Garantiza orden
  • Usa puertos

Three-Way Handshake

  • SYN
  • SYN-ACK
  • ACK
🔒 TCP prioriza fiabilidad sobre velocidad.
❌ Más lento que UDP.

¿Qué protocolo garantiza entrega?



7.3 UDP

  • Sin conexión
  • Más rápido
  • No fiable
  • Poco overhead

Usos

  • Streaming
  • VoIP
  • Gaming
  • DNS
⚡ UDP sacrifica fiabilidad por velocidad.
⚠ No retransmite paquetes perdidos.

¿Qué protocolo es más rápido?



7.4 TCP vs UDP

TCP UDP
Fiable No fiable
Más lento Más rápido
Con conexión Sin conexión
ACK y control flujo Sin control
🎮 Juegos online suelen usar UDP.

7.5 ICMP

ICMP reporta errores y diagnósticos.

  • Ping
  • Traceroute
  • TTL exceeded
  • Destination unreachable
📡 Ping usa Echo Request/Reply.
⚠ ICMP no transporta datos de usuario.

¿Qué herramienta usa ICMP?



7.6 SSH

  • Administración remota segura
  • Cifrado
  • Puerto 22
  • Sustituye Telnet
🔐 SSH cifra comandos y contraseñas.
❌ Telnet transmite datos sin cifrar.

¿Qué puerto usa SSH?



7.7 RARP

  • MAC → IP
  • Obsoleto
  • Sustituido por DHCP
💡 Es el “contrario” de ARP.
⚠ No asignaba gateway ni DNS.

¿Qué hace RARP?



7.8 ARP

  • IP → MAC
  • Funciona en LAN
  • Usa broadcast
📦 Ethernet necesita MACs para enviar tramas.
⚠ ARP Request = broadcast.

¿Qué traduce ARP?



7.9 ARP Spoofing

Ataque donde se envían respuestas ARP falsas.

  • MITM
  • Robo tráfico
  • ARP poisoning

Protecciones

  • DAI
  • DHCP Snooping
  • HTTPS/SSH
☠ El atacante se hace pasar por el router.

¿Qué permite ARP Spoofing?



7.10 DHCP

  • Asignación automática IP
  • Gateway
  • DNS
  • Máscara

Tipos

  • Dinámica
  • Automática
  • Reserva
📡 DHCP evita configurar IPs manualmente.
⚠ Las reservas DHCP se asocian a MACs.

¿Qué asigna DHCP?

7.12 STP - Spanning Tree Protocol

Evita bucles en redes conmutadas.

  • Usa Root Bridge
  • Previene broadcast storms
  • Bloquea enlaces redundantes
🌳 STP crea una topología libre de bucles.
❌ Sin STP pueden existir tormentas broadcast.

¿Qué evita STP?



7.13 STP - Puertos

  • Root Port
  • Designated Port
  • Blocked Port
  • Alternate Port
🔄 El Root Port es el mejor camino al Root Bridge.
⚠ Solo hay un Root Port por switch.

¿Qué puerto evita bucles?



7.14 STP - Ventajas y desventajas

Ventajas Desventajas
