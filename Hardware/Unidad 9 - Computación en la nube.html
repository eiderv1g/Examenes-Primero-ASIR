1. Introducción al cloud computing

El cloud computing permite usar recursos informáticos a través de Internet sin tener servidores físicos propios.

Recursos cloud

  • Servidores.
  • Bases de datos.
  • Almacenamiento.
  • Aplicaciones.
  • Redes.
On-Premise Cloud
Hardware propio Infraestructura alquilada
Gran inversión inicial Pago por uso
Mantenimiento interno Servicios gestionados
La nube transforma productos físicos en servicios flexibles.
Cloud no significa “sin servidores”; los servidores existen en CPDs remotos.

2. IaaS - Infrastructure as a Service

El proveedor ofrece infraestructura básica: máquinas virtuales, almacenamiento y red.

Proveedor gestiona Tú gestionas
Hardware y virtualización Sistema operativo
Red física Aplicaciones
Almacenamiento Datos

Ejemplos

  • AWS EC2.
  • Azure Virtual Machines.
  • Google Compute Engine.
IaaS ofrece gran flexibilidad y control técnico.
Cuanto más control tienes, más responsabilidad asumes.

3. PaaS y SaaS

PaaS

El proveedor también administra el sistema operativo y middleware.

SaaS

Usas aplicaciones listas para funcionar desde navegador o app.

Modelo Tú haces
PaaS Desarrollar apps
SaaS Usar el servicio

Ejemplos

  • PaaS → Google App Engine.
  • PaaS → Azure App Service.
  • SaaS → Gmail, Google Drive, Microsoft 365.
SaaS es el modelo más usado por usuarios finales.
PaaS reduce muchísimo tareas de administración.

5. Responsabilidad compartida

La nube funciona bajo un modelo de responsabilidad compartida.

Proveedor Cliente
Infraestructura física Permisos
Red y CPD Configuración
Hardware Protección datos

Importancia

  • Configurar accesos correctamente.
  • Evitar buckets públicos.
  • Gestionar usuarios y roles.
  • Aplicar MFA.
La mayoría de brechas cloud ocurren por mala configuración.
La nube NO asegura automáticamente tus datos.

6. Serverless y Edge Computing

Serverless / FaaS

  • Ejecución por eventos.
  • Pago por milisegundos.
  • Escalado automático.

Edge Computing

  • Procesamiento cerca del usuario.
  • Menor latencia.
  • Ideal para IoT y gaming.
Tecnología Ventaja
Serverless No administrar servidores
Edge Respuesta ultrarrápida
Serverless revoluciona aplicaciones basadas en eventos.
Serverless NO significa que no existan servidores físicos.

10. Resumen final examen

Conceptos imprescindibles

  • IaaS → infraestructura.
  • PaaS → plataforma.
  • SaaS → software listo.
  • AWS, Azure y GCP dominan el mercado.
  • Serverless ejecuta código por eventos.
  • Edge reduce latencia.
  • MFA y IaC son fundamentales.
