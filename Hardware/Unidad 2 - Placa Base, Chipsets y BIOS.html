1. La placa base

La placa base (motherboard) es el componente central del ordenador. Actúa como sistema nervioso y esqueleto del PC. Todos los componentes dependen de ella para comunicarse.

Funciones principales

  • Interconectar CPU, RAM y almacenamiento.
  • Distribuir energía.
  • Coordinar buses y señales.
  • Permitir expansión mediante PCIe.
Dato clave:
Sin placa base, CPU, RAM y GPU serían componentes aislados incapaces de trabajar juntos.
Pregunta trampa:
La placa base NO mejora directamente los FPS o velocidad del sistema.

2. Componentes principales

Componente Función

DIMM Slots Instalación de memoria RAM

Detalles importantes

Cada CPU necesita un socket específico. Intel y AMD utilizan plataformas incompatibles.

Error clásico:
Comprar una CPU incompatible con el socket de la placa.
Curiosidad:
La ranura PCIe x16 suele reservarse para la GPU porque tiene el mayor ancho de banda.

3. Chipsets y buses

El chipset controla el tráfico de datos entre CPU, RAM, PCIe y periféricos.

Buses principales

Bus Función
Bus de datos Transporta información
Bus de direcciones Indica dónde leer/escribir
Bus de control Coordina señales y sincronización

Funciones del chipset

  • Gestionar USB.
  • Controlar PCIe.
  • Compatibilidad RAM.
  • Permitir overclocking.
Chipset = "controlador de tráfico" de la placa base.
No todos los chipsets permiten overclocking.

6. BIOS vs UEFI

La BIOS/UEFI es el firmware encargado de iniciar el hardware antes de cargar el sistema operativo.

BIOS UEFI
Interfaz texto Interfaz gráfica
16 bits 32/64 bits
Límite 2.2 TB Compatible discos enormes
Sin Secure Boot Secure Boot integrado
UEFI reemplazó prácticamente por completo a la BIOS tradicional.
UEFI NO es solo una BIOS con gráficos bonitos.

7. POST y proceso de arranque

Secuencia de arranque

  1. Se pulsa el botón de encendido.
  2. La fuente envía señal Power Good.
  3. CPU ejecuta BIOS/UEFI.
  4. POST comprueba hardware.
  5. Se busca dispositivo de arranque.
  6. Se carga bootloader del SO.
POST significa Power-On Self-Test.
Pitidos o códigos LED durante POST indican errores hardware.

8. Secure Boot y GPT

UEFI introdujo importantes mejoras de seguridad y almacenamiento.

GPT

  • Reemplaza MBR.
  • Permite discos superiores a 2.2 TB.
  • Más particiones.

Secure Boot

  • Impide malware en arranque.
  • Verifica firmas digitales.
  • Protege bootloader.
GPT y Secure Boot son dos pilares de los PCs modernos.
MBR tiene limitaciones importantes frente a GPT.

9. Configuración práctica BIOS/UEFI

Tareas habituales

  • Cambiar Boot Order.
  • Activar virtualización.
  • Monitorizar temperaturas.
  • Configurar ventiladores.
  • Establecer contraseñas.

Boot Order

Para instalar un sistema operativo desde USB, el pendrive debe estar como primera opción de arranque.

El técnico cambia constantemente el Boot Order en instalaciones.
VirtualBox y VMware permiten practicar sin riesgos.
