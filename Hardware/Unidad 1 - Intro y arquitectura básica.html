1. Arquitectura Von Neumann

La arquitectura Von Neumann es la base conceptual de prácticamente todos los ordenadores modernos. Fue propuesta en 1945 por John von Neumann y revolucionó la informática.

Idea principal

Tanto los datos como las instrucciones se almacenan en la misma memoria principal. Gracias a esto, el ordenador puede ejecutar distintos programas sin cambiar físicamente el hardware.

Dato importante de examen:
La unificación de datos e instrucciones en la RAM es la característica más importante de Von Neumann.

Ventajas

  • Flexibilidad para ejecutar diferentes programas.
  • Diseño más simple que arquitecturas anteriores.
  • Escalable a cualquier dispositivo.
Pregunta trampa:
Muchos tests preguntan si CPU y RAM son lo mismo. NO lo son: la CPU procesa y la RAM almacena temporalmente.

2. CPU y componentes internos

La CPU (Unidad Central de Procesamiento) es el cerebro del ordenador. Interpreta y ejecuta instrucciones.

Componente Función
CU (Unidad de Control) Coordina todas las operaciones del sistema.
ALU Realiza operaciones matemáticas y lógicas.
Registros Memoria ultrarrápida interna.
Curiosidad:
Los procesadores actuales contienen miles de millones de transistores.
Error típico:
Más GHz NO siempre significa más rendimiento.

3. Memoria RAM

La memoria RAM es el espacio de trabajo temporal del ordenador.

Características

  • Almacena instrucciones y datos temporales.
  • Es volátil: se borra al apagar el equipo.
  • Cuanta más RAM, mejor multitarea.
Pregunta frecuente:
La RAM NO guarda datos permanentemente.

Ejemplo

Cuando abres Chrome o un videojuego, el programa se carga desde el SSD/HDD hacia la RAM.

4. Entrada/Salida y buses

El subsistema E/S conecta el ordenador con el mundo exterior.

Periféricos de entrada

  • Teclado
  • Ratón
  • Micrófono

Periféricos de salida

  • Monitor
  • Impresora
  • Altavoces

Buses

Bus Función
Datos Transporta información
Direcciones Indica dónde leer/escribir
Control Coordina señales
Los buses son las "autopistas" internas del ordenador.

5. Caso de estudio: iPhone 2007

Apple revolucionó la informática móvil integrando múltiples componentes en un SoC (System on a Chip).

Claves del éxito

  • CPU, GPU y RAM integradas.
  • Memoria flash NAND.
  • Pantalla multitáctil.
  • iOS derivado de macOS.
Curiosidad:
Los smartphones actuales siguen usando el mismo principio de arquitectura Von Neumann.

10. Mitos y preguntas trampa

Mito: "Solo importan los GHz"

El rendimiento depende también de:

  • Número de núcleos.
  • Caché.
  • Arquitectura.
  • Velocidad del almacenamiento.
Mito: "Software libre = mala calidad"

Linux, Apache y PostgreSQL son ejemplos de software libre extremadamente robusto.

Pregunta típica de examen:

¿Qué diferencia hay entre freeware y software libre?
