1. Introducción a los backups

Una copia de seguridad es la red de seguridad digital de cualquier sistema.

¿Por qué son esenciales?

  • Protección frente a fallos hardware.
  • Recuperación tras ransomware.
  • Evitar pérdidas por error humano.
  • Garantizar continuidad empresarial.
Riesgo Consecuencia
Disco roto Pérdida de datos
Virus Cifrado o borrado
Error humano Eliminación accidental
Un backup bien diseñado puede salvar una empresa completa.
Si el backup no puede restaurarse, no sirve de nada.

2. Copias de archivos vs imágenes completas

Tipo Incluye
Copia de archivos Documentos y carpetas
Imagen de respaldo TODO el sistema

Imagen completa

  • Sistema operativo.
  • Drivers.
  • Programas.
  • Configuraciones.
  • Usuarios.
Una imagen de respaldo es como congelar el PC en un instante.
Copiar solo carpetas NO protege el sistema completo.

3. Bare-Metal Restore

Permite reconstruir un sistema desde cero en un disco vacío.

Ventajas

  • Recuperación rápida.
  • No reinstalar Windows.
  • Recuperar programas y drivers.
  • Reducir tiempo de inactividad.
Proceso tradicional Bare-Metal
Reinstalar todo manualmente Restauración automática
Horas o días Minutos
Es fundamental en empresas y servidores críticos.
Pregunta trampa: un backup de archivos NO permite bare-metal restore.

4. P2V y V2P

Tecnología Función
P2V Físico → Virtual
V2P Virtual → Físico

P2V

  • Migrar sistemas antiguos.
  • Preservar software legado.
  • Facilitar backups y replicación.

V2P

  • Volver a hardware real.
  • Compatibilidad específica.
  • Casos industriales antiguos.
P2V es muy utilizado para conservar servidores antiguos.
El sistema operativo "cree" que sigue funcionando igual.

6. Regla 3-2-1

Regla esencial del backup

  • 3 copias totales.
  • 2 soportes distintos.
  • 1 copia fuera del lugar físico.
Ejemplo Función
SSD interno Original
Disco externo Copia local
Nube Copia remota
Protege frente a robos, incendios y ransomware.
RAID NO sustituye una copia de seguridad real.

7. Tipos de mantenimiento

Tipo Objetivo
Correctivo Reparar tras el fallo
Preventivo Evitar fallos
Predictivo Anticipar averías

Ejemplos

  • Cambiar fuente quemada → Correctivo.
  • Limpiar polvo → Preventivo.
  • Detectar sectores dañados → Predictivo.
El mantenimiento profesional combina los tres enfoques.
Trabajar solo de forma reactiva genera más costes.

8. Monitorización y SMART

Herramientas importantes

Herramienta Función
HWiNFO Temperaturas y sensores
CrystalDiskInfo Estado SMART
Zabbix Monitorización empresarial
Nagios Alertas y supervisión

Qué monitorizar

  • Temperaturas.
  • Voltajes.
  • Velocidad ventiladores.
  • Errores SMART.
  • Latencia red.
SMART puede avisar meses antes de un fallo total.
Ignorar temperaturas altas acorta la vida útil del hardware.

9. Herramientas y errores comunes

Mantenimiento físico

  • Aire comprimido.
  • Brochas antiestáticas.
  • Cambio pasta térmica.
  • Revisión ventiladores.
Mito Realidad
"Si funciona no necesita mantenimiento" El polvo degrada el hardware
"Monitorizar ralentiza" El impacto es mínimo
Un PC limpio trabaja más frío y dura más años.
Siempre descargar electricidad estática antes de manipular hardware.

10. Resumen final examen

Conceptos imprescindibles

  • Imagen de respaldo = copia total del sistema.
  • Bare-metal = restauración completa.
  • P2V → físico a virtual.
  • Regla 3-2-1 = estándar profesional.
  • Predictivo = anticipación basada en datos.
  • SMART ayuda a detectar fallos.

Preguntas trampa típicas

Pregunta Respuesta correcta
¿RAID sustituye backup? No
¿Copiar carpetas basta? No
¿P2V virtualiza? Sí
La monitorización predictiva evita caídas y pérdidas económicas.
El error humano sigue siendo una de las principales causas de pérdida de datos.
