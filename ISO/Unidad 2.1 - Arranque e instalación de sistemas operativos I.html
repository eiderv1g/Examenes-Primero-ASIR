2.1 El proceso de arranque

El arranque es la secuencia de eventos que comienza cuando pulsas el botón de encendido y termina cuando el kernel del sistema operativo toma el control total del hardware.

Fases principales

Fase Descripción
POST Comprobación de hardware básico
Firmware BIOS o UEFI inicia el sistema
Bootloader Selecciona y carga el sistema operativo
Kernel Controla memoria, CPU y drivers
Init/Systemd Arranque de servicios y entorno usuario

POST (Power-On Self Test)

El firmware comprueba:

  • RAM
  • CPU
  • Teclado
  • GPU
  • Discos
⚠ Si el POST falla, normalmente escucharás pitidos o verás códigos de error.

Secuencia técnica real

Encendido → POST → BIOS/UEFI → Bootloader → Kernel → Sistema Operativo
💡 En Linux el kernel suele llamarse vmlinuz y se acompaña del initramfs.

2.2 BIOS vs UEFI

BIOS y UEFI son firmwares encargados de iniciar el hardware y preparar el sistema operativo.

BIOS

  • Sistema antiguo
  • Modo Legacy
  • Usa MBR
  • Límite 2,2 TB
  • Interfaz muy básica

UEFI

  • Firmware moderno
  • Compatible con GPT
  • Usa archivos .EFI
  • Soporta Secure Boot
  • Permite múltiples entradas de arranque
Característica BIOS UEFI
Modo Legacy Moderno
Particionado MBR GPT
Arranque Sector MBR Archivos EFI
Seguridad Baja Secure Boot
⚠ Pregunta trampa: “UEFI necesita obligatoriamente GPT”. Parcialmente falso. Puede usar CSM.

ESP (EFI System Partition)

Partición FAT32 donde se guardan los archivos .EFI:

\EFI\Microsoft\Boot\bootmgfw.efi \EFI\ubuntu\grubx64.efi
💡 En equipos modernos siempre se recomienda UEFI + GPT.

2.3 Bootloaders

El bootloader es el programa encargado de cargar el sistema operativo.

Bootloaders más importantes

Bootloader Sistema Estado
GRUB2 Linux Actual
BOOTMGR Windows Actual
LILO Linux Obsoleto

¿Qué hace GRUB?

  • Muestra menú de sistemas
  • Carga kernels Linux
  • Detecta Windows
  • Permite rescate
  • Gestiona dual boot

GRUB en UEFI

\EFI\ubuntu\grubx64.efi

BOOTMGR

Windows usa BOOTMGR o bootmgfw.efi.

\EFI\Microsoft\Boot\bootmgfw.efi
⚠ LILO ya NO se considera moderno.

2.4 Tipos de arranque

Legacy

Modo compatible con BIOS tradicional.

  • Usa MBR
  • Compatible con equipos antiguos
  • Limitado

Secure Boot

UEFI verifica firmas digitales para impedir malware en el arranque.

Multi-Boot

Permite elegir varios sistemas operativos desde un menú.

Tipo Características
Legacy Compatibilidad antigua
Seguro Validación criptográfica
Múltiple Varios sistemas
💡 GRUB detecta automáticamente Windows y Linux.
⚠ Ambos sistemas deben instalarse en el mismo modo: UEFI + UEFI o Legacy + Legacy.

2.5 Caso de estudio: GRUB

GRUB2 se convirtió en el estándar Linux por su modularidad y soporte UEFI.

Ventajas

  • Compatibilidad con UEFI
  • Compatibilidad Secure Boot
  • Rescate del sistema
  • Configuración flexible
  • Soporte RAID y LVM

Comandos importantes

sudo update-grub
sudo grub-install /dev/sda
sudo grub-install --target=x86_64-efi --efi-directory=/boot/efi

Shim y Secure Boot

Ubuntu y Debian usan shim firmado digitalmente para permitir Linux con Secure Boot activo.

💡 Gracias a shim NO necesitas desactivar Secure Boot normalmente.

2.6 Herramientas, consejos y buenas prácticas

efibootmgr

sudo efibootmgr

Permite:

  • Ver entradas UEFI
  • Cambiar BootOrder
  • Eliminar entradas

bcdedit

bcdedit /enum

Administra el arranque Windows.

mokutil

mokutil --sb-state

Comprueba estado de Secure Boot.

Buenas prácticas

  • Usar UEFI + GPT
  • Hacer copia de ESP
  • Documentar BootOrder
  • Evitar mezclar Legacy y UEFI
⚠ Nunca borres la carpeta EFI sin copia de seguridad.

2.8 Microsoft Media Creation Tool

Herramienta oficial de Microsoft para crear medios de instalación Windows.

Ventajas

  • ISO oficial
  • Compatibilidad UEFI
  • USB automático
  • Versiones actualizadas

Proceso recomendado

  1. Descargar MCT
  2. Seleccionar edición
  3. Elegir arquitectura x64
  4. Crear USB
  5. Probar arranque

Herramientas relacionadas

Herramienta Uso
Rufus USB avanzado
Ventoy Multiboot
DiskPart Particionado
DISM Drivers e imágenes
💡 Rufus permite configurar GPT/UEFI o MBR/BIOS manualmente.

2.9 Herramientas útiles y recuperación

bootrec

bootrec /fixmbr bootrec /fixboot bootrec /rebuildbcd

Repara arranque Windows.

TestDisk

Recupera particiones dañadas o eliminadas.

mbr2gpt

mbr2gpt /convert

Convierte discos sin borrar datos.

Boot-Repair

Repara automáticamente GRUB.

Problemas típicos

  • GRUB desaparece
  • BOOTMGR is missing
  • ESP corrupta
  • MBR dañado
  • Windows sobrescribe GRUB
⚠ Windows Update puede modificar BootOrder.
💡 Siempre lleva un Live USB de rescate.
